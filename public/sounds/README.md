# sounds/ — required files

Place these exact filenames directly in this folder (`public/sounds/`). Sound effects are
optional at runtime (the game stays fully playable with silence if a file is missing or fails
to load), but all five are part of the finished design.

- pop.mp3
- crunch.mp3
- boing.mp3
- plop.mp3
- win.mp3

**None of these 5 files are included in this project** — they were never supplied to the assistant
that built this project. Copy your original MP3s in here before deploying. Once a real file is
added, you can delete this README (or leave it — it won't be served by the app, it's just
documentation).
